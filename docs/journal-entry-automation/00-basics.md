# 00 経理・仕訳の基礎（顧客と会話するための最低限）

[← 目次へ](./README.md)

> **この章のゴール**
> - 顧客の経理担当者の話を聞いて「何の話か」が分かる
> - 1件の請求書を見て、仕訳の各項目が何を意味するか説明できる
> - AIが間違えやすい仕訳の型を知っていて、評価データに入れられる
>
> 簿記の資格は不要です。ただし、**この章の例題くらいは自分で仕訳を切れる** ようにしておくと、ヒアリングの質が段違いに上がります。

---

## 1. 経理の仕事の中で「仕訳入力」はどこにあるか

```
［日々］                         ［月次］                   ［年次］
請求書・領収書が届く             月次決算（締め）              年次決算・税務申告
  ↓                              ・入力漏れ/誤りチェック        ・決算整理仕訳
仕訳を入力する ← ここが対象        ・前払/未払の振替             ・法人税・消費税申告
  ↓                              ・部門別の集計               ・監査対応
承認する                          ・経営への月次報告
  ↓
支払う・入金を消し込む
```

仕訳入力の誤りは **月次決算のチェック工程で見つかり、手戻りになる** ことが多いです。
つまり「入力が速くなった」だけでなく「月次の手戻りが減った」まで見ないと、本当の効果は分かりません。

## 2. 仕訳のしくみ（5分で分かる版）

### 借方（かりかた）・貸方（かしかた）

取引を必ず **2つの側面** に分けて記録します。左が借方、右が貸方で、**左右の合計は必ず一致** します。

| 分類 | 増えたら | 減ったら | 例 |
|---|---|---|---|
| 資産 | 借方（左） | 貸方（右） | 現金、預金、売掛金、備品、前払費用、仮払消費税 |
| 負債 | 貸方（右） | 借方（左） | 買掛金、未払金、預り金、借入金 |
| 純資産 | 貸方（右） | 借方（左） | 資本金 |
| 費用 | 借方（左） | 貸方（右） | 通信費、旅費交通費、消耗品費、外注費 |
| 収益 | 貸方（右） | 借方（左） | 売上高、受取利息 |

仕訳入力業務で扱うのは、ほとんどが **「費用が発生した（借方）／お金を払う義務ができた（貸方）」** の形です。

### 1件の仕訳を構成する項目

会計ソフトに入れるとき、1行あたりおおむね次の項目があります。**AIに当てさせたいのは主に★の項目** です。

| 項目 | 例 | 説明 |
|---|---|---|
| 伝票日付 | 2026-09-30 | 計上日。請求日・納品日・検収日のどれにするかは会社ルール |
| ★借方 勘定科目 | 通信費 | 何にお金を使ったか |
| ★借方 補助科目 | クラウド利用料 | 科目をさらに細かく分けたもの（会社ごとに自由） |
| ★部門 | 情報システム部 | どの部署の費用か |
| ★税区分 | 課税仕入10% | 消費税の扱い |
| ★金額 | 100,000 | 税抜 or 税込は会社の経理方式による |
| 貸方 勘定科目 | 未払金 | 支払い義務 |
| 取引先 | ○○株式会社 | 補助科目や取引先マスタで管理することが多い |
| ★摘要 | 9月分 クラウド利用料 | 何の取引かのメモ。社内ルールで書き方が決まっていることが多い |
| 証憑番号 | INV-2026-0912 | 元の請求書を辿るための番号 |

### 税込経理と税抜経理

- **税抜経理**：費用は税抜で計上し、消費税は「仮払消費税」として別に記録する（中堅以上の企業で多い）
- **税込経理**：消費税込みの金額で費用を計上する（小規模企業で見かける）

→ キックオフで **必ず確認** してください。AIの出力形式（金額の分け方）が変わります。

## 3. 例題で覚える：よく出る仕訳の型

以下はすべて **税抜経理** の例です。

### 型A：毎月同じ請求書（いちばん簡単）

> 9月分のクラウド利用料 110,000円（税込、10%）の請求書が届いた。翌月末払い。

| 借方 | 金額 | 貸方 | 金額 |
|---|---|---|---|
| 通信費（部門：情報システム部） | 100,000 | 未払金 | 110,000 |
| 仮払消費税（課税仕入10%） | 10,000 | | |

**ポイント**：取引先が決まれば科目もほぼ決まる。過去の仕訳を真似すれば当たる。
→ AIを使わなくても「前回と同じ」ルールでかなり当たる型。

### 型B：商品の仕入（買掛金と未払金の違い）

> 卸売の本業として、食品メーカーから商品 550,000円（税込、8%軽減税率）を仕入れた。

| 借方 | 金額 | 貸方 | 金額 |
|---|---|---|---|
| 仕入高 | 509,260 | 買掛金 | 550,000 |
| 仮払消費税（課税仕入8%軽減） | 40,740 | | |

**ポイント**：本業の仕入の未払いは **買掛金**、それ以外（経費・備品）の未払いは **未払金** と使い分ける会社が多い。
食品なので **軽減税率8%**。端数の扱い（請求書に記載の消費税額を使う）にも注意。

### 型C：1枚のレシートに税率が混在

> 会議用の飲料 2,160円（8%）と文房具 1,100円（10%）を1枚のレシートで購入。従業員が立替えた。

| 借方 | 金額 | 貸方 | 金額 |
|---|---|---|---|
| 会議費 | 2,000 | 未払金（従業員立替） | 3,260 |
| 仮払消費税（課税仕入8%軽減） | 160 | | |
| 消耗品費 | 1,000 | | |
| 仮払消費税（課税仕入10%） | 100 | | |

**ポイント**：**明細を読まないと科目も税区分も決まらない**。行を分けて仕訳する（複合仕訳）。AIが間違えやすい代表例。

### 型D：明細が多く、毎回中身が違う請求書

> 事務用品の通販会社から、コピー用紙・トナー・椅子・ノートPC用スタンドなど25行の明細の請求書が届いた。

**ポイント**：
- 明細ごとに科目が違う（消耗品費、事務用品費、場合によっては備品）
- 部門ごとに注文していれば、明細ごとに部門も違う
- 従来の「取引先ごとに過去の仕訳を補完する」方式では対応できず、人が1行ずつ入力していた領域
- LayerX が「AI明細仕訳」で狙っているのがまさにこの型（[参考資料](./references.md)）

### 型E：金額によって科目が変わる（固定資産 or 費用）

> ノートPCを1台 250,000円（税抜）で購入した。

| 取得価額（税抜経理なら税抜） | 一般的な扱い |
|---|---|
| 10万円未満 | 消耗品費などで全額その期の費用 |
| 10万円以上20万円未満 | 一括償却資産として3年で均等償却する選択肢あり |
| 中小企業者等の特例 | 令和8年度改正で **40万円未満** に拡大（年間合計300万円まで、従業員数などの要件あり）。即時に費用化できる |
| 上記以外 | 工具器具備品などの固定資産に計上し、耐用年数で減価償却 |

**ポイント**：**同じ「ノートPC」でも金額と会社の方針で正解が変わる**。会社がどの特例を使っているか、経理規程で必ず確認。
税制の閾値は改正で変わるので、**ルールとしてAIの外に持たせる**（プロンプトに数字を埋め込みっぱなしにしない）のが安全。

### 型F：源泉徴収が必要な支払い

> 個人のデザイナーにロゴ制作を依頼し、報酬 100,000円 ＋ 消費税 10,000円の請求書が届いた。

| 借方 | 金額 | 貸方 | 金額 |
|---|---|---|---|
| 支払手数料（または外注費・広告宣伝費） | 100,000 | 預り金（源泉所得税） | 10,210 |
| 仮払消費税（課税仕入10%） | 10,000 | 未払金 | 99,790 |

**ポイント**：個人へのデザイン料・原稿料・士業報酬などは、支払側が所得税を差し引いて納める（源泉徴収。100万円以下の部分は10.21%）。
**「相手が法人か個人か」で仕訳が変わる**。請求書の見た目だけでは判定しづらい難所。

### 型G：前払・期間按分

> 12か月分のソフトウェア保守料 1,320,000円（税込）を一括で支払った。

会社の方針により、
- 一旦「前払費用」に計上して毎月 100,000円ずつ費用へ振り替える、または
- 一定の要件（短期前払費用の特例）を満たす場合は支払時に全額費用にする

**ポイント**：**1枚の請求書から、その後12回の振替仕訳が生まれる**ことがある。会社ルール次第。

### 型H：部門への按分（配賦）

> 本社ビルの家賃 1,100,000円（税込）を、面積比で営業部60%・管理部40%に分ける。

**ポイント**：按分の比率は社内で決まっている（毎月同じ）。AIに推測させるより **マスタとして持たせる**。

### 型I：海外サービス・外貨

> 海外のSaaSから USD 建ての請求書が届いた。

**ポイント**：
- 円換算のレート（請求日か支払日か、TTMか）が会社ルールで決まっている
- 海外事業者からの役務提供は、消費税の扱いが特殊な場合がある（リバースチャージ方式、海外事業者のインボイス登録の有無など）
- → 新人は判断しない。**「海外サービスはこう処理している」というルールを経理担当から聞き出す** のが仕事

## 4. 税区分とインボイス制度（最低限）

### よく使う税区分

| 税区分 | 例 |
|---|---|
| 課税仕入 10% | ほとんどの経費 |
| 課税仕入 8%（軽減税率） | 飲食料品（酒類・外食を除く）、定期購読の新聞 |
| 非課税仕入 | 土地の購入、住宅家賃、保険料、利息、一部の手数料 |
| 不課税（対象外） | 給与、寄付金、海外での取引の一部、税金・印紙 |
| 免税 | 輸出取引など |

会社の会計ソフトでは、さらに「課税売上対応／共通対応」など細かい区分がある場合があります。**区分のリストは必ず顧客の会計ソフトのマスタから貰う** こと。

### インボイス制度（適格請求書）

- 請求書に **登録番号（T＋13桁）** があれば「適格請求書」。消費税を全額控除できる
- 登録番号がない（免税事業者など）からの仕入は、**経過措置** で控除できる割合が決まっている

| 仕入れの時期 | 控除できる割合 |
|---|---|
| 2023年10月1日〜2026年9月30日 | 80% |
| **2026年10月1日〜2028年9月30日** | **70%** |
| 2028年10月1日〜2030年9月30日 | 50% |
| 2030年10月1日〜2031年9月30日 | 30% |

※令和8年度税制改正による。1つの免税事業者等からの仕入が年1億円を超える部分は対象外となるなどの制限もある。

**AI案件でのポイント**：
- 登録番号の有無・正しさ（国税庁の公表サイトで確認できる）で税区分が変わる
- **2026年10月はちょうど控除割合が変わった月**。9月以前と10月以降のデータでは正解の税区分が変わりうる。評価データの期間に注意

### 電子帳簿保存法

電子で受け取った請求書（PDFなど）は電子のまま保存する義務があります。
AIで読み取ったデータを保存する場合も、**元の証憑との紐付け**（いつ・誰が・どの証憑から入力したか）が求められます。システム設計時に情シス・経理と確認しましょう。

## 5. 「AIが間違えやすい仕訳」チェックリスト

評価データセットを作るときは、ここにある型が **必ず入っている** ことを確認してください（→ [03 データと評価の設計](./03-data-and-eval.md)）。

- [ ] 明細行が多い請求書（型D）
- [ ] 1枚に税率が混在する（型C）
- [ ] 金額で科目が変わる（固定資産と費用の境目、型E）
- [ ] 個人への支払いで源泉徴収あり（型F）
- [ ] 前払・期間按分（型G）
- [ ] 部門按分・配賦（型H）
- [ ] 外貨・海外サービス（型I）
- [ ] 登録番号なし（免税事業者）の請求書
- [ ] 値引き・返品・マイナス行を含む請求書
- [ ] 初めて取引する取引先（過去の仕訳がない）
- [ ] 同じ取引先なのに、内容によって科目が変わる（例：同じ通販会社から消耗品と備品）
- [ ] 手書き・スキャン品質の悪い証憑、罫線のない表

## 理解度チェック

1. 型Aの請求書が「AIを使わなくても当たる」のはなぜか？
2. 同じ「ノートPC購入」でも正解の科目が変わるのはどんなときか？
3. 個人のデザイナーへの支払いで、法人への支払いと何が変わるか？
4. 2026年9月の請求書と10月の請求書で、免税事業者からの仕入の扱いはどう変わるか？

<details><summary>答え</summary>

1. 取引先ごとに科目・部門・税区分がほぼ固定で、過去の仕訳をそのまま再利用すれば当たるから。
2. 取得価額（10万円・20万円・40万円などの閾値）と、会社がどの特例を使う方針かで変わる。
3. 源泉徴収が必要になり、預り金の行が増え、支払額が減る。
4. 控除できる割合が80%から70%に下がる（令和8年度改正の経過措置）。

</details>

# キキガキ

熟練者にインタビューして、業務の暗黙知（何を手がかりに、どう決め、いつ例外にするか）を引き出し、後任が読める「判断メモ」にするアプリのプロトタイプです。

UIは「インテント・リバースマップ」から逆算して作っています。要求からいきなりUIを作るのではなく、ゴールまでのステップごとに「思考の視線」「保持している情報」「行動」を先に書き切り、最後の「到達方法」で初めてUIを決めています。

- [`intent-reverse-map.md`](./intent-reverse-map.md)：マップ本体（ゴール、7ステップ×7項目、到達方法の候補と外した理由、仮説、検算）
- [`index.html`](./index.html)：プロトタイプ。マップのデータもこの中にあり、画面上の「設計の根拠」とマップ表示は同じデータから描かれます

## 画面とステップの対応

| ステップ | 画面 | ギャップを埋める仕掛け |
|---|---|---|
| S1 依頼を受け止める | 招待 | 受け手・見られる範囲・かかる時間・判断メモの見本を先に見せる |
| S2 ある1日を思い出す | インタビュー | 最初の問いを「段取りを変えた具体的な1日」に固定する |
| S3 その日の流れを話す | インタビュー＋聞き書きノート | 話した内容を時刻順のタイムラインに積み、「◆ 分かれ目」に印を付ける |
| S4 理由を言葉にする | インタビュー | AIが手がかりの仮説を出し、話し手は「そう／少し違う／違う」で正す。後任ならどうするかを対比で聞く |
| S5 例外と確かさを決める | 判断カード | 「もし／なら／ただし」の3段と、言葉で選ぶ確かさ（いつも／たいてい／場合による） |
| S6 業務に戻り、また戻ってくる | 中断・再開 | 言いかけたことを1行残し、再開時に「前回まで／あなたのメモ／次に伺うこと」を出す |
| S7 確かめて渡す | 確認 | AIの補いだけを番号付きで並べ、0件になると渡せる。受け手が読む形でも見られる |

## 動かし方

`index.html` は claude.ai の Artifact として公開する前提のページ断片です（`<!doctype>` や `<head>` は公開時に付きます）。ブラウザで直接開いてもデモは動きます。

- **デモ**：配車担当22年の佐藤さんが、後任の木村さんに「天気が崩れそうな日の配車」を残す台本です。上部のステップ（S1〜S7）を押すと、その場面に飛べます。
- **自分の業務で試す**：AIが聞き手になり、入力したテーマで実際にインタビューします。claude.ai で開いたときだけ使えます（Artifact の `sample` 機能を使い、閲覧者の Claude の利用枠を使います）。途中の内容はそのブラウザにだけ保存され、次に開いたときに「続きから」再開できます。

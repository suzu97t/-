# results.md — 計算結果・感度分析・不確かな点

再現方法：`cd shinuhodo && python3 calc.py`（matplotlib が必要）。以下の数値はすべてこの出力から転記した。

## 1. 結論（先に）

**面白くはなった。ただし予想した方向ではなかった。**
「死ぬほど疲れた日」は、エネルギーで見ると**ほぼ普段の日と同じ**だった。

| 指標 | 値 |
|---|---|
| 死ぬほど疲れた日の総消費 | **2,684 kcal**（普段の日は2,589 kcal） |
| 普段の日との差 | **＋95 kcal**（バナナ約1本） |
| 持続可能な上限（基礎代謝×2.5 = 3,656 kcal）に対して | **73%** |
| 大陸横断レース走者（5,350〜6,200 kcal/日）に対して | 43〜50% |
| 体の燃料の貯金（約10.6万 kcal）に対して | 総消費で2.5%、普段との差だけなら**0.09%** |
| 何も食べずに毎日繰り返した場合 | **68日**で致死ライン（普段の日なら71日。**差は3日**） |
| 普通に食べて毎日繰り返した場合 | 体重は約62 kgで釣り合う。**死なない** |

疲れの正体はエネルギー不足ではない。体の燃料の家計で見ると、「死ぬほど疲れた日」は**黒字**である。

## 3. 1日の消費（METs積み上げ）

計算式：kcal = 1.05 × METs × 時間 × 65 kg。最後に、食事誘発性熱産生を総消費の10%として加えた（÷0.9）。

### 普段の日（睡眠7h、デスク7.5h）

| 行動 | 時間 | METs | kcal |
|---|---|---|---|
| 睡眠 | 7.00 | 0.95 | 454 |
| 身支度 | 0.50 | 2.5 | 85 |
| 食事 | 1.25 | 1.5 | 128 |
| 通勤の徒歩 | 0.50 | 3.5 | 119 |
| 駅の階段 | 0.10 | 4.0 | 27 |
| 満員電車で立つ | 1.50 | 1.3 | 133 |
| デスクワーク | 7.50 | 1.5 | 768 |
| 社内移動・立ち仕事 | 1.00 | 2.8 | 191 |
| シャワー | 0.25 | 2.0 | 34 |
| 帰宅後ソファで放心 | 4.40 | 1.3 | 390 |
| **合計** | 24.00 | 34.14 METs·h | 活動2,330 → **2,589**（PAL 1.77） |

### 死ぬほど疲れた日（睡眠5h、デスク10.5h、終電帰り）

| 行動 | 時間 | METs | kcal |
|---|---|---|---|
| 睡眠 | 5.00 | 0.95 | 324 |
| 身支度 | 0.50 | 2.5 | 85 |
| 食事 | 1.00 | 1.5 | 102 |
| 通勤の徒歩 | 0.50 | 3.5 | 119 |
| 駅の階段 | 0.10 | 4.0 | 27 |
| 満員電車で立つ | 1.50 | 1.3 | 133 |
| デスクワーク | **10.50** | 1.5 | **1,075** |
| 社内移動・立ち仕事 | 1.00 | 2.8 | 191 |
| シャワー | 0.25 | 2.0 | 34 |
| 帰宅後ソファで放心 | 3.65 | 1.3 | 324 |
| **合計** | 24.00 | 35.39 METs·h | 活動2,416 → **2,684**（PAL 1.84） |

**なぜ差が小さいのか**
睡眠（0.95）とソファ（1.3）の時間が、デスクワーク（1.5）に置き換わっただけだからである。METsの差は0.2〜0.55しかなく、5時間置き換えても約1.25 METs·h（約95 kcal）にとどまる。

### 参考：肉体労働の日（引越し作業8時間）
**5,149 kcal**（PAL 3.52、上限の141%）。
「体が」死ぬほど疲れた日なら、上限を超える。ただしこれは1日だけの話である。上限は数週間以上続けた場合の値なので、1日超えても直ちに危険という意味ではない。

## 5. 食べずに続けたら（思考実験）

Hallらのモデル定数で、赤字を脂肪と除脂肪組織に分配した。消費は体重に比例して下がると仮定し、代謝適応は無視した。致死ラインは次のうち早い方とした。
- 必須脂肪まで減った時点
- BMI 13（約37.6 kg）に達した時点

すべてのケースでBMI 13のラインに先に到達した。

|---|---|---|
| 普段の日 | 71日 | 37.2 kg（43%減） |
| **死ぬほど疲れた日** | **68日** | 37.4 kg（42%減） |
| 肉体労働の日 | 36日 | 36.9 kg（43%減） |

## 6. 伝令（F）

ここでは65 kgの人が走った場合として計算した。正味コストは1 kcal/kg/km。

| 距離 | 正味コスト | 「普段との差95 kcal」換算 | 貯金比 |
|---|---|---|---|
| アテネ→スパルタ 240 km（ヘロドトスの話。死んでいない） | 15,600 kcal | **165日分** | 15% |
| マラトン→アテネ 40 km（死んだという伝説） | 2,600 kcal | 27日分 | 2.4% |

伝説で伝令が「死んだ」40 kmでも、貯金の2.4%にすぎない。エネルギー切れで死んだと考えるのは無理がある。死因を説明するなら熱中症などの急性の経路になるが、それは今回の範囲外（C）である。

## 7. 感度分析

| 前提（低 / 高） | 普段との差 kcal | 上限比 % | 貯金比 % | 絶食日数 |
|---|---|---|---|---|
| **基準** | **95** | **73** | **2.5** | **68** |
| 体重 55 / 75 kg | 80 / 109 | 73 / 73 | 2.5 / 2.5 | 50 / 81 |
| 体脂肪率 12 / 28 % | 95 / 95 | 73 / 73 | 4.7 / 1.7 | 50 / 81 |
| 死ぬほど日の睡眠 3 / 7 h | 178 / 11 | 76 / 71 | 2.6 / 2.4 | 66 / 70 |
| 電車で立つ 1.3 / 2.0 METs | 95 / 95 | 73 / 76 | 2.5 / 2.6 | 68 / 66 |
| METs換算 1.00 / 1.05 | 90 / 95 | 70 / 73 | 2.4 / 2.5 | 72 / 68 |
| 食事誘発性熱産生 0 / 10 % | 85 / 95 | 66 / 73 | 2.3 / 2.5 | 68 / 68 |
| 基礎代謝をMifflin式で | 95 | 70 | 2.5 | 68 |
| 持続上限 2.5 / 3.0×BMR | 95 | 73 / 61 | 2.5 | 68 |
| 脂肪 9,441 / 7,700 kcal/kg | 95 | 73 | 3.1 / 2.5 | 59 / 68 |
| 必須脂肪 3 / 5 % | 95 | 73 | 2.5 / 2.9 | 68 |
| **盛る側をすべて重ねる**（睡眠3h、電車2.0、75kg、体脂肪12%） | 206 | **78** | 5.0 | 43 |

**読み方**
- どの前提を変えても、**上限比は61〜78%**。盛る側の前提をすべて重ねても上限（100%）には届かない。結論は頑健。
- 「普段との差」は睡眠時間に最も敏感（3時間睡眠で178 kcal＝バナナ約2本）。それでもバナナ2本である。
- 絶食日数は体格（体重・体脂肪率）で50〜81日と大きく変わる。この数字を画面に出すなら幅で示すべき。
- **気温**は感度分析に入れていない。今回のエネルギーモデルでは、気温を消費量に反映する信頼できる係数が見つからなかった。気温が効くのは熱中症などの急性の経路（C）で、今回の範囲外である。数字をでっち上げないために、項目ごと除外した。

## 9. 不確かな点

1. **METsの版**：2011年版の値を使った。2024年版で改訂された値がある可能性がある（特に「立つ」は1.3→2.0の可能性）。ただし感度分析で、上限比への影響は3ポイント以内だった。
2. **基礎代謝基準値**：2025年版の22.5は二次情報で確認した。2020年版の表に22.3と読める記載もある。差は1%未満。
3. **持続上限2.5×BMR**は、Thurberらが**測定したBMR**に対する倍率である。日本の基準値によるBMRに当てはめるのは近似。Mifflin式で置き換えると上限比は70%。
4. **2.5倍は長期（数週間〜）の上限**であり、1日の上限ではない。「1日でも超えたら危険」という意味ではないので、台本で混同しないこと。
5. **大陸横断走者の消費**は2016年の修士論文の値で、2019年論文の値と一致するかは未確認。
6. **飢餓モデル**
   - 消費が体重に比例する、と単純化している
   - 代謝適応（飢餓で代謝が下がる効果）を無視している
   - 実際には電解質異常や感染症など、エネルギー以外の原因で死亡することが多い
   - **日数は桁の目安**であり、予測値ではない
7. **致死ラインBMI 13**は集団の傾向で、明確な閾値ではない（文献によって12〜13）。
8. **身長170 cm**は仮置き。致死体重は身長の2乗で変わる。
9. **伝令の距離・体重**：240 kmは現代の推定。伝令の体重は不明なので、65 kgの視聴者が走った場合として換算した。
10. **バナナ1本＝93 kcal**は「可食部100 g」として換算した。実際のバナナ1本の可食部は大きさで変わる。
11. **「疲れた」の中身**：精神的な疲労・眠気・ストレスは、このモデルでは原理的に測れない。「エネルギー的には余裕」は「体が平気」という意味ではない。
